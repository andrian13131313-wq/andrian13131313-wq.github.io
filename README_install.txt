Застосунок «Тести ЛБФМК Марченко» — встановлення на GitHub
==========================================================
1. github.com → «+» → New repository.
   Repository name — ТОЧНО: andrian13131313-wq.github.io   · Public · Create repository.
2. «uploading an existing file» → перетягніть УСІ файли з цієї папки
   (index.html, tests.json, manifest.webmanifest, sw.js, .nojekyll, іконки *.png) → Commit changes.
3. Через 1–2 хв відкрийте на телефоні: https://andrian13131313-wq.github.io/
   Android (Chrome): кнопка «Встановити» на сторінці або меню ⋮ → «Установити застосунок».
   iPhone (Safari): «Поділитися» → «На початковий екран» → «Додати».
4. Новий тест у застосунку: допишіть його в tests.json (або передайте Claude) і завантажте файл заново.
Тести, підручники й тренажери лишаються у своїх репозиторіях (krok-antimicrobials, edki-farmakognoziya).
